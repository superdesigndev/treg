A few things to know.

Do I need a separate subscription for every provider?

No. For supported catalog tools, treg handles the provider connection and meters your usage against one prepaid balance. Some tools use your own connected accounts, such as Google Analytics or Search Console.

Can Astra find phone numbers too?

Yes. Ask for phone enrichment alongside work emails. Availability and pricing vary by provider and contact, so not every profile will have a phone number.

Is the benchmark an Astra evaluation?

The comparison shown here uses Claude Code with and without treg. It demonstrates the value of giving an agent access to people-search tools; it is not an Astra benchmark.

Can I use treg outside Codex?

Yes. treg also works with Claude Code, OpenClaw, Hermes and other agents. Explore supported agents.
