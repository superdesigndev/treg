Treg plugin for Claude

Published by SuperdesignSource: superdesigndev/treg

One install: the Treg skill and Treg's tools

The plugin gives Claude the Treg skill, which teaches it how to find, price and call a tool, and connects Treg's MCP server, which makes the calls. Claude can then use Treg's catalog and your team's own tools without holding an API key. It is a third-party community plugin published by Superdesign; it is not an Anthropic product or a claim of Anthropic verification.

01Install

In Claude Code:

/plugin marketplace add superdesigndev/treg
/plugin install treg@treg
  1. Run /mcp, pick plugin:treg:treg, and choose Authenticate. Claude opens Treg's OAuth consent page.
  2. Sign in to Treg, select the team Claude may use, review the requested access, and approve.
  3. The Treg tools appear in Claude. Ask for a task, for example "find the search volume for a keyword, and tell me the cost first".

In the Claude apps, install Treg from the plugin directory and connect it the same way. The plugin needs no token and no configuration. Authentication uses OAuth with PKCE; do not paste a Treg token or provider API key into Claude. The plugin's server is {BASE}/mcp/.

02What the plugin includes

The Treg skill tells Claude to search the catalog by task, read an endpoint's inputs and price, state the cost before a metered call, and report what it spent.

The Treg tools on the MCP server:

  • catalog_search and catalog_get find endpoints and show their input, authentication, method, and price.
  • call invokes a catalog endpoint or one of your team's own tools. Some catalog endpoints change data at the provider (for example, publish a post or change an ad budget), so call is marked as a tool that can make changes, and Claude can ask you before it runs.
  • call_media invokes an audio endpoint and returns the audio to Claude.
  • my_tools lists what your team has registered: its own API keys, OAuth connections, and skills.
  • resources_list lists items your team created with Treg's provider accounts, for example a cloned voice.
  • balance reports the selected team's prepaid balance and daily usage.
  • catalog_request, feedback and review record a missing capability, a problem, or a rating of a call. They do not call a provider.

The catalog includes image, video, and voice generation. The plugin cannot call arbitrary URLs: every call goes to a catalog endpoint or to one of your team's own tools.

03Pricing and limits

Installing the plugin, searching, and inspecting the catalog are free. Before a metered call, Treg returns the endpoint's USD price. Calls served with Treg's platform credential debit the selected team's prepaid balance. Calls with your team's own key are never metered by Treg; the provider bills you directly. Your team's balance and daily cap are enforced before calls. See the current Pricing page.

04Data flow and security

Claude sends the chosen endpoint id and request inputs to Treg. Treg applies the selected team's access rules and spending limits, injects the applicable credential server-side, and relays the request to that endpoint's provider. The provider response is returned to Claude without reshaping it. Provider credentials are never returned to Claude.

Treg records call metadata needed for metering, audit, reliability, and support. Provider request and response data necessarily pass through Treg to complete the call. Read the full privacy policy for retention, processors, and account-data rights, and the terms of service.

05Uninstall and revoke

In Claude Code, run /plugin uninstall treg@treg. In the Claude apps, remove the plugin from your plugin settings. To revoke the underlying authorization from Treg as well, sign in to Treg and remove the Claude grant from the connected-apps area, or ask Support to revoke it. Uninstalling does not delete your Treg team, balance, provider connections, or audit history.

06Support

For setup, billing, privacy, security, or endpoint problems, visit Treg support or email jason@superdesign.dev. Include the endpoint id, approximate time, and the error text, but never send passwords, OAuth codes, tokens, or API keys. The plugin's source is public at github.com/superdesigndev/treg.
