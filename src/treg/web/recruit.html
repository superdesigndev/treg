How a run goes

The recruit skill turns your agent into the sourcer. It shows you the criteria before it spends anything, and every stage is counted in a run file you can check.

  1. Read the jobFrom the LinkedIn post URL, or the text you paste.
  2. Agree the criteriaTitle variants, must-have skills, seniority, location. Shown to you in five lines first.
  3. SearchOne routed people search per title variant, across the people-data vendors.
  4. Filter and rankDrops the wrong location, seniority or job family, with a reason for each. Ranks the rest with one line on why.
  5. Check the evidenceCited facts from career history, code, talks and posts move a candidate up or down.
  6. Find the contactsPersonal email and mobile for the shortlist, cheapest vendor first, each one verified.
