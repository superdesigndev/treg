treg for Sheets

Published by SuperdesignGoogle Workspace add-on

Live data in your spreadsheet, without API keys

treg for Sheets runs tools from treg's catalog on the rows of your spreadsheet: company and people data, search results, web pages and more. You pick the tool and the input columns; the add-on writes the answers back into the sheet. You never paste a provider API key into Sheets.

01What it does

  • Fill empty cells row by row. Choose a tool, map your columns to its inputs, and the add-on fills the empty answer cells of each row you select.
  • Make new rows from one query. Run a search-style tool once and write each result it returns as a new row.
  • =TREG() formulas. Call a tool from a cell, like any other spreadsheet formula, with the cell values as its inputs.

02Sign in and who pays

Open the add-on's panel in Google Sheets and sign in with your treg account. Choose the treg team that should pay; every run is charged to that team's prepaid balance, under the team's own access rules and spending limits. Tools that use a provider credential your team connected follow that provider's own billing as well. See pricing.

03Every run shows its cost first

Before a run starts, the panel shows what it will cost for the rows you selected, and nothing is charged until you confirm.

04Your data

The add-on reads only the spreadsheet you have open: the cells you pick as inputs, the header row and your selection. It sends treg the tool id and the input values of each row you run, and writes the answers back into that spreadsheet. Your treg sign-in token is kept in your own Google add-on storage, never in the sheet. The full details, including Google's Limited Use requirements, are in the privacy policy.

05Stop using it

Sign out in the add-on's panel to revoke its treg sign-in, and uninstall the add-on from Google Sheets (Extensions → Add-ons → Manage add-ons). Removing the add-on does not delete your treg team, balance or call history.

06Support

For setup, billing or privacy questions, email unclecode@superdesign.dev or visit treg support. Never send passwords, sign-in codes, tokens or API keys.
