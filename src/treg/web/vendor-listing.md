# List your API in the treg catalog: instructions for a coding agent

You are helping an API vendor get listed in treg's tool catalog ({BASE}). The deliverable is one
pull request to https://github.com/superdesigndev/treg that adds the API to the catalog.

1. Clone https://github.com/superdesigndev/treg.
2. Follow the skill `.agents/skills/vendor-listing/SKILL.md` in that repository
   (https://github.com/superdesigndev/treg/blob/main/.agents/skills/vendor-listing/SKILL.md). It
   is the complete instruction set: eligibility, what the pull request contains, how to verify it
   with your own key, and what its description must carry.
3. Put a contact email for the vendor's team in the pull request description. treg's maintainers
   email it about the next steps once the pull request is up.
