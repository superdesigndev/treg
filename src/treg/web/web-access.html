Steer it with four headers

Options ride as headers, never in the body, so the call stays the vendor's own request.

X-Treg-Route-PreferTry a vendor first, like free TinyFish.
X-Treg-Route-ExcludeSkip a vendor that gave you bad answers.
X-Treg-Route-Max-CostCap one call. Without it, a miss can walk up to $1 of vendors.
X-Treg-Route-WaterfallSet to 0 to stop at the first miss.
